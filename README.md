# EKS Vehicle Flipper

A simple, reliable, and immersive way to flip overturned vehicles in FiveM using ox_target.

## Features

* Flip any overturned vehicle via third-eye interaction
* Safe repositioning to prevent vehicles landing on players
* Short push animation during flip
* Smooth and network-safe vehicle correction
* Fully compatible with **ox_target**
* Lightweight and optimized

## Installation

1. Drag and drop the folder into your `resources/` directory
2. Add the following to your `server.cfg`:

     ensure EKS_CarFlip

3. Start or restart your server | no configuration required.
